## Question 2:
"Can you share a time when you faced a major challenge in a project and how you handled it?"

In one of my previous projects for a UI-focused client, we faced a major challenge.  
The deadlines were very tight, and at the same time, new features kept being introduced frequently. The problem was that the project's existing architecture and components, which were developed by a previous team, were not scalable or well-organized.

As part of the development team, I identified that simply adding new features on top of the poorly structured code would slow us down and cause more technical debt in the future.  
So, we proposed to the client to allocate some time specifically for refactoring the existing components — making them dynamic, modular, and reusable — so we wouldn't have to build new components from scratch for every feature.

Fortunately, after explaining the long-term benefits, the client agreed to give us that additional time. After refactoring, we were able to implement new features much faster and deliver a more stable and scalable app. The client was very satisfied with the final product, and the overall development process became much smoother after that.

## Question 8:
"What would you do if you discovered an issue after merging your code into the production branch?"

If I discovered an issue after merging my code into the production branch, my first step would be to immediately check the logs and try to reproduce the error in a local environment. I would investigate the root cause by looking at recent changes, the stack trace, and any other relevant details to identify where the problem originated. If the issue is critical, I would revert the merge and deploy a hotfix as quickly as possible to minimize any negative impact on users. I would then collaborate with the team to investigate further, make necessary corrections, and run thorough tests to ensure the fix works as expected. Communication with the team and stakeholders would be essential, so everyone is updated on the status of the issue and the resolution. Finally, I'd document the issue and steps taken to prevent similar problems in the future.
